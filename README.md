# connordibble.dev

Personal portfolio for Connor Dibble, focused on full stack software engineering, design systems, platform engineering, and AI-assisted developer tooling.

## Stack

- Next.js 16 App Router
- React 19
- Tailwind CSS 4
- Framer Motion
- TypeScript

## Development

Use `pnpm`.

```bash
pnpm install
pnpm dev
pnpm lint
pnpm build
```

## Project Notes

- Visual direction lives in `DESIGN.md`.
- Portfolio sections live in `src/components/`.
- Public resume is served from `public/resume.pdf`.
- App icons and social preview images are generated through Next.js metadata routes in `src/app/`.

## Design Intent

Quiet, precise, and technical. Graphite surfaces, crisp typography, sparse accent color, and no decorative filler.
